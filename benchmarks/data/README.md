# Graph Atlas provenance

`atlas.dat.gz` is the unmodified Graph Atlas data distributed with NetworkX 3.5.
It contains the 1,253 graphs on at most seven vertices from Read and Wilson,
*An Atlas of Graphs*, Oxford University Press, 1998.

Source: https://raw.githubusercontent.com/networkx/networkx/networkx-3.5/networkx/generators/atlas.dat.gz

Documentation: https://networkx.org/documentation/stable/reference/generated/networkx.generators.atlas.graph_atlas_g.html

SHA256: `73fc416df0164923607751cb759f4ae81deb5f6550bf25be59c86de3b747e41d`.

NetworkX is distributed under its BSD 3-Clause license; see
https://github.com/networkx/networkx/blob/networkx-3.5/LICENSE.txt.
The unmodified license text is retained in `NETWORKX_LICENSE.txt`.
This data is used as an implementation correctness audit, not as a measured
real-world temporal-network benchmark.
